# Contributing to the tap

This tap holds the Homebrew formulae for nerdlabz software. The `evado`
formula is generated by each release of
[nerdlabz/evado-tui](https://github.com/nerdlabz/evado-tui), so a new version
arrives here as a pull request with that release's checksums.

Open an issue here if installing, upgrading or `brew test` goes wrong, and say
which formula, your platform, and the output of `brew config`. Problems with
Evado itself, once it is installed, belong in
[evado-tui](https://github.com/nerdlabz/evado-tui/issues).

Pull requests that fix a formula are welcome. Check them with:

```sh
brew style Formula/evado.rb
brew audit --formula nerdlabz/tap/evado
brew install --build-from-source nerdlabz/tap/evado && brew test nerdlabz/tap/evado
```

Contributions made with AI tools follow the same terms as the main project,
described in its [contributing guide](https://github.com/nerdlabz/evado-tui/blob/main/CONTRIBUTING.md#using-ai-tools):
a person opens every issue and pull request and stands behind it.

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
