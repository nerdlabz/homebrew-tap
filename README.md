# nerdlabz Homebrew tap

Homebrew formulae for nerdlabz software, on macOS and Linux.

```sh
brew install nerdlabz/tap/evado
```

| Formula | What it is |
| --- | --- |
| `evado` | [Evado](https://evado.app) in the terminal: a todo TUI and CLI that works with or without an account. Source: [nerdlabz/evado-tui](https://github.com/nerdlabz/evado-tui) |

The formulae install prebuilt release binaries for ARM64 and x86-64, checked
against the SHA-256 sums published with each release.

To upgrade, run `brew update && brew upgrade evado`. Report problems with a
formula here, and problems with the program itself in its own repository.
